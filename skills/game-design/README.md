# SkillForge Game Design

SkillForge Game Design is a practical design skillset for creating, revising,
critiquing, and playtesting playable systems and content. It helps a model make
design decisions that can be tested at the table or in a build, rather than
stopping at theme or description.

[Download the current release](../../releases/SkillForge-Game-Design.zip) ·
[Release details and checksum](../../releases/README.md)

## Use it for

- core mechanics, loops, resources, progression, and balance;
- player characters, adversaries, encounters, and challenge calibration;
- adventures, scenarios, clues, hubs, and exploration structures;
- worldbuilding that creates actionable play;
- critique, iteration, playtesting, and focused design Drills.

## How it works

The root `SKILL.md` selects a bounded execution mode and retrieves only the
relevant Action Procedures, Patterns, and Drills. Shared metaskills support
planning, option generation, and verification. The package distinguishes
between explaining a design and producing the actual playable artifact a task
requires.

## Install

Install or upload the ZIP as one skill. If the host expects a directory, extract
the archive and point it at the extracted `SkillForge_Game_Design` folder. The
entry point is `SKILL.md`.

Python is optional. Its bundled helpers provide deterministic routing and blind
Drill administration; the design judgment remains in the Markdown library.

## Persistence boundary

The release may include a read-only snapshot of Game Design Skillset Memory.
That is test evidence about the skill, not project continuity or user memory,
and it never overrides the canonical cards. Rebuilds and changes originate in
PASS.
