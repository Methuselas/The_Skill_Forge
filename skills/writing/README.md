# SkillForge Writing

SkillForge Writing is a craft and revision skillset for producing written work,
diagnosing drafts, and practising specific capabilities. It supports both
generative work and exacting revision without collapsing every genre into one
generic writing prompt.

[Download the current release](../../releases/SkillForge-Writing.zip) ·
[Release details and checksum](../../releases/README.md)

## Use it for

- fiction, scene craft, viewpoint, character, dialogue, and structure;
- poetry, form, lineation, rhythm, sound, imagery, and voice;
- creative nonfiction and life writing;
- college admission essays and career documents;
- adventure-module writing, critique, revision, feedback, and practice.

## How it works

The root `SKILL.md` routes the task to the relevant genre and craft modules, then
loads a bounded set of Action Procedures, Patterns, and Drills. Shared
metaskills support creative search, iterative construction, and verification.
The skill distinguishes producing a requested artifact from merely describing
how one could be written.

## Install

Install or upload the ZIP as one skill. If the host expects a directory, extract
the archive and point it at the extracted `SkillForge_Writing` folder. The entry
point is `SKILL.md`.

Python is optional. Its bundled helpers can resolve runtime requirements and
administer blind Drills; the actual writing and editorial judgment remain in
the Markdown library.

## Persistence boundary

The release may include a read-only snapshot of Writing Skillset Memory. It is
empirical test evidence, not canonical writing knowledge, project continuity,
or user memory. Rebuilds and changes originate in PASS.
