## Process boundary

The four Stages are unchanged. Dodson's Search / Control rhythm complements them:
- Stage 1 — Search
- Stage 2 — Control of Stage 1
- Stage 3 — Search
- Stage 4 — Control of Stage 3

Smaller Search / Control loops may occur inside a Stage when the work requires reopening exploration or tightening a decision.

## Lighting ownership

Composition owns why lighting is designed: mood, narrative emphasis, focal hierarchy, shadow pattern, ambient/color intent, and deliberate expressive departures from literal illumination.

Rendering owns how the chosen illumination affects local value/color, form, edge, shadow, reflected light, and material response.

## Memory / learning boundary

Memcaps may be used as provenance-bearing accumulated project experience: prior teaching, corrections, failure patterns, successful outcomes, and judgments. AI must not invent lived experience or pretend an unrecorded memory exists.

After Art is complete, drills are intended not only to test canon but to create useful experience:
canon -> attempt -> inspect -> diagnose -> teach/correct -> extract lesson -> preserve memory -> apply next attempt.
