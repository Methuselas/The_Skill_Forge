# Package Emailed Application Documents for Reliable Routing

## Pattern Rule
**IF** a resume and cover letter must be submitted as email attachments
**THEN** package them in the requested, readily openable form with identifiers that route the files and message to the correct vacancy

## Do
- Follow the advertised file-format instruction; when none is given, confirm the recipient's preference or choose a widely accepted format that preserves the document.
- Put the advertised job title and reference number in the subject line so the message can be sorted without opening attachments.
- Name each file with the applicant's identity and document type rather than a generic label shared by hundreds of candidates.
- Keep formatted documents as attachments when pasting them into the message body would damage layout or legibility.
- Recheck the recipient address, filenames, document versions, and actual attachments immediately before sending.

## Don't
- Assume a file that opens on the sender's computer will open in an obscure or proprietary format for the recipient.
- Call the attachment only `resume` or `cover letter` and force the recruiter to rename it after download.
- Send the message before confirming that the intended files, rather than drafts or unrelated versions, are attached.
- Ignore an explicit submission instruction because another packaging choice looks more polished.

## Checklist
- Every attachment uses the requested or confirmed acceptable format.
- Filenames identify both the applicant and the document type.
- The subject line identifies the vacancy and includes its reference number when one exists.
- The final rendered files retain their intended formatting and are readable when reopened.
- The recipient, attachments, and versions have been verified in the outgoing message.

## Notes
Submission packaging is part of the application because a document that cannot be opened, identified, or routed may never reach evaluation. The decisive rule is recipient compatibility, not loyalty to a particular format. Clear filenames and vacancy identifiers also keep the materials attached to their context after the email itself is no longer visible.
