# Proofread Application Materials with Independent Passes

## Pattern Rule
**IF** application content and structure are stable enough for final error removal
**THEN** inspect the complete package through several independent reading modes so familiarity and automated checking cannot hide the same class of mistake

## Do
- Run automated spelling and grammar checks after setting the intended language variety, then review every proposed change rather than accepting it blindly.
- Read the documents aloud or from a printed rendering to expose skipped words, awkward repetition, and punctuation the eye has learned to glide over.
- Make a separate slow pass for punctuation, duplicate spaces, inconsistent capitalization, and wrong-word substitutions that remain valid dictionary words.
- Ask another careful reader to inspect the final files without relying on the writer's memory of what each sentence was meant to say.
- Repeat the check on the rendered or transmitted version after any correction that could reflow the layout.

## Don't
- Treat a clean spellcheck result as proof that names, dates, homophones, punctuation, and attachment contents are correct.
- Proofread while still making large content changes that will invalidate the inspected lines and page flow.
- Let an automated checker silently convert the document to an unintended regional spelling convention.
- Ask a second reader only whether the application is good instead of requesting an error-focused pass.

## Checklist
- The intended spelling convention is consistent across all documents.
- Every proper name, employer, role title, date, number, email address, and telephone number has been checked directly.
- At least one pass changed the visual or auditory mode of reading.
- A separate reader or equivalent independent pass inspected the final wording.
- Corrections did not introduce new spacing, pagination, or attachment-version errors.

## Notes
Each pass should make a different failure visible. Automation catches many surface errors but accepts valid wrong words; reading aloud disturbs visual familiarity; a slow mechanical pass catches spacing and punctuation; another reader lacks the writer's private reconstruction of missing text. The sequence begins only after substantive changes are stable.
