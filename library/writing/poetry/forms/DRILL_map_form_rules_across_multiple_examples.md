# Map Poetic Form Rules Across Multiple Examples

## Practice Task
Build and test a working specification for one inherited poetic form by matching its stated rules against several accomplished poems.

## Target Skill
Formal literacy and deliberate adaptation in poetry.

## Setup
Choose one named form, a reliable concise description of it, and at least three complete examples. Include more than one practitioner and, when available, both a strict and a contemporary execution.

## Instructions
1. Make separate rows for line count, stanza pattern, meter or syllables, rhyme, repeated material, structural turns, and customary subject features.
2. Translate the description into a checkable rule for each applicable row; mark a row not applicable rather than inventing a requirement.
3. Annotate every example against the map and record exactly where it follows or departs from each rule.
4. Compare the departures. Classify a feature as governing, commonly variable, or uncertain based on the evidence rather than on one poem.
5. State what recognizable action survives in each varied example, such as a refrain cycle, a volta, or a recurring end-word pattern.
6. Draft a short plan for a new poem that names the rules it will keep and one optional departure with its intended effect.

## Success Check
- Each applicable row states a rule checkable against a poem, and rows without evidence are marked not applicable rather than filled with an invented requirement.
- Every example is annotated against every row, including rows it satisfies unremarkably.
- Classification as governing, commonly variable, or uncertain rests on the pattern across examples rather than on the most admired one.
- Each varied example has its surviving recognizable action stated, so variation is distinguished from abandonment.
- At least one asserted rule is found not to govern, or its survival across every example is recorded as evidence rather than assumed.
- The specification is usable by someone who has not read these particular poems.

## Common Failures
- Treating the description as sufficient without checking how poems execute it.
- Choosing several examples that all imitate one another and reveal no boundary cases.
- Labeling every difference innovation without identifying the governing feature it preserves.
- Planning a departure because it is easier rather than because it changes the poem productively.

## Notes
Formal knowledge becomes usable when abstract rules can be recognized in actual poems. Comparison exposes which constraints create the form's characteristic pressure and which admit established variation, giving a writer both firmer control and more honest freedom.
