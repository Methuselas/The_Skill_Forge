# Preserve Exploratory Draft Variants with Lightweight Labels

## Pattern Rule
**IF** an early creative project is producing competing openings, endings, plans, scenes, character versions, or partial drafts whose value cannot yet be judged
**THEN** preserve the branches and add only enough naming, grouping, summary, and version order to retrieve and compare them during a later evaluative pass
**ELSE** consolidate the working set once the draft has established which alternatives serve the whole

## Do
- Separate notes, sketches, character material, scene experiments, and continuous drafts when those categories make retrieval faster.
- Give each branch a descriptive working name and an ordered version marker instead of repeatedly overwriting a generically named file.
- Add a one- or two-sentence account of what happens in a scene or chapter when its filename cannot make the content findable.
- Save the current state before a major structural change, changed premise, new narrator, or replacement of one long passage by another.
- Move false starts and cut scenes out of the active draft while keeping them available until the surviving design no longer depends on them.
- Review alternatives together only when the current pass is ready to select by purpose, consequence, and fit with the emerging whole.

## Don't
- Delete an exploratory branch because it appears messy before another version supplies evidence for comparison.
- Treat organizational neatness as proof that the creative problem is solved.
- Build an elaborate taxonomy, color system, or archive whose upkeep repeatedly delays writing.
- Keep several unlabeled copies whose chronology, contents, or relation cannot later be reconstructed.
- Paste every promising fragment into the active draft merely to avoid choosing among them.
- Preserve all alternatives forever after the work has stabilized and the comparison has been made.

## Checklist
- Every live branch can be identified without opening a long sequence of ambiguous files.
- Version order and the current active draft are unambiguous.
- Scene or chapter summaries make key material retrievable where names alone are insufficient.
- Consequential changes begin from a recoverable earlier state.
- Cut or abandoned material is separated from, not silently mixed into, the active draft.
- Consolidation follows an evaluative decision about the whole rather than discomfort with creative mess.

## Notes
Exploration creates surplus: the writer often has to try a scene, follow a mistaken plan, or draft incompatible possibilities before enough of the story exists to choose. Premature cleanup turns uncertainty into irreversible loss; no organization turns useful surplus into an inaccessible heap. The working system should therefore preserve option value at low cost. Labels, version order, brief summaries, and a clear active draft create enough structure for later judgment without demanding that discovery behave like final production.
