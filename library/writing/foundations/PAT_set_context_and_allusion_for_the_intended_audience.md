# Set Context and Allusion for the Intended Audience

## Pattern Rule
**IF** a passage depends on people, events, references, or shared history that only some readers will know
**THEN** decide whether the work is private or seeks a broader audience, then supply, transform, or deliberately withhold context according to that goal

## Do
- Name the actual reader: one intimate, a familiar community, a workshop, or an unknown public.
- Mark allusions that work only because the first imagined reader already knows the people or incidents involved.
- For a broader audience, add enough orientation that the reference can create its intended effect without private knowledge.
- Judge feedback about accessibility against the work's ultimate destination rather than accepting it automatically.
- Revisit the decision when the work moves from private circulation toward publication.

## Don't
- Do not assume that context shared with a best friend is available to a classroom or public readership.
- Do not explain every reference merely because one reader missed it; mystery or insider recognition may be part of the design.
- Do not claim a broad audience while making comprehension depend on undisclosed private history.

## Checklist
- Who is meant to read this version?
- Which references require knowledge outside the words on the page?
- Does each omission or explanation serve the chosen audience?
- If peer advice asks for more access, does the final goal support that revision?

## Notes
Starkey tests the decision with one story written for a best friend and then offered to a class. Private allusions work for the first audience and fail for the second, but the correct revision depends on whether the story is meant to remain personal or reach beyond that relationship. Accessibility is therefore a responsibility created by audience choice, not a universal demand for maximum explanation.
