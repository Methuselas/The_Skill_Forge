# Build TTRPG Worlds from Player Facing Pressures
## Pattern Rule
**IF** inventing a TTRPG setting
**THEN** develop the institutions, customs, resources, and places that change what player characters can do.
## Do
- Start from daily pressures players will encounter: travel, law, worship, work, trade, or survival.
- Develop setting detail when it creates a choice, obstacle, ally, or adventure opportunity.
## Don't
- Treat encyclopedic background as a substitute for playable world information.
## Checklist
- Each developed setting element affects a likely character action.
- The opening area supplies enough information to begin play.
## Notes
A game world is a stage for decisions. Detail earns its place when players can encounter, use, resist, or transform it.
