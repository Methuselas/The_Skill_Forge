# Audit a TTRPG Session for Design Signals
## Practice Task
Observe one session as a designer.
## Target Skill
Separate TTRPG Design Friction from Personal Preference.
## Setup
Use a game session or a short rules excerpt with a played example.
## Instructions
Record each rule lookup, disagreement, delayed turn, and meaningful choice. For each, state the observed event, then list competing causes before naming one transferable lesson.
## Success Check
The notes include both a preference and an observable design signal without confusing them.
## Common Failures
- Treating one player's taste as proof of a universal flaw.
- Recording a complaint without the event that produced it.
## Notes
Repeat with games of different rules weight to avoid mistaking one preferred style for a universal standard.
