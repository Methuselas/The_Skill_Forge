# Budget Renewable Reserves Against Future Demands

## Pattern Rule
**IF** one refreshable reserve can improve several different actions, defenses, or consequences before it refreshes
**THEN** make players allocate that reserve while later demands are still uncertain, with a refresh cadence long enough that spending now changes vulnerability or capability later in the same cycle
**ELSE** use a static bonus or simpler per-action resource when future allocation does not create a real tradeoff.

## Do
- Give the reserve at least two materially different uses, such as offense versus defense, effect versus self-protection, or position versus later recovery.
- Refresh at a clear cadence that contains several plausible demands; turn, scene, exchange, or another bounded cycle should be chosen by the decisions it creates rather than by convention.
- Require commitment before all later threats are known when uncertainty is part of the intended tension.
- Let unspent reserve remain useful until refresh so caution and aggression are both viable strategies.
- Cap reserve augmentation when necessary so temporary leverage amplifies trained capability rather than replacing it.
- Test the resource under both one-threat and multiple-threat situations; a pool that is interesting only when the future is obvious is not doing much tactical work.

## Don't
- Refresh the reserve after every action when the intended choice depends on conserving it for later actions.
- Give every use the same practical outcome under different names.
- Make the optimal allocation obvious because one use dominates every representative situation.
- Treat a large reserve as interesting merely because it creates large dice pools or modifiers.

## Checklist
- At least two uses compete for the same reserve before refresh.
- Spending on one use measurably reduces options or reliability for a later plausible use.
- The refresh cadence has been tested with more than one demand inside the cycle.
- A conservative and an aggressive allocation are each rational in at least one representative state.
- The reserve does not routinely substitute for missing foundational training unless that substitution is intentional.

## Notes
A renewable reserve creates more decision value when it represents **when to commit capability**, not merely additional capability. The key is unresolved future demand: spending heavily on the present action should expose the character to a believable later need before the resource returns. This makes the reserve a short-horizon risk budget rather than a static bonus with extra bookkeeping.
