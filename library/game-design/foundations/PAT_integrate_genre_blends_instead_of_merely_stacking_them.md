# Integrate Genre Blends Instead of Merely Stacking Them

## Pattern Rule
**IF** a game combines two or more recognizable genres
**THEN** identify the defining play requirements of each, locate where their assumptions reinforce or conflict, and design the combination so each remains causally and mechanically meaningful
**ELSE** keep a single-genre foundation rather than adding elements that function only as decoration.

## Do
- List the capabilities, threats, resources, institutions, and recurring behaviors each genre normally makes important.
- Identify contradictions between genre assumptions, such as empowerment versus vulnerability, abundance versus scarcity, or technological solutions versus supernatural uncertainty.
- Resolve those contradictions deliberately so the combined design explains where both sets of assumptions can be true at once.
- Let the component genres change one another through world history, social structures, character options, security, economics, conflict, and mechanics.
- Test whether removing one component would materially alter player options, threats, conflicts, or world behavior; if not, examine whether it is actually integrated.

## Don't
- Treat genre fusion as a list of recognizable props from multiple genres.
- Add one genre's defining feature in a form that another genre immediately makes irrelevant.
- Create parallel genre subsystems that never meaningfully interact.
- Assume internal logic will emerge automatically from juxtaposition.

## Checklist
- Each genre contributes at least one recurring play requirement that remains relevant after the blend.
- Conflicting assumptions have an explicit design resolution rather than being ignored.
- The setting contains causal reasons for the genres to coexist and affect one another.
- Character builds, threats, and problem-solving methods reflect the combined design rather than separate isolated layers.
- Removing one genre component would materially change how the game is played or understood.

## Notes
A successful genre blend is an integration problem, not an asset-merging problem. The component genres should exert pressure on one another so the combination produces consequences neither would have alone. Strong fusion therefore preserves the functions that make each genre recognizable while allowing the interaction between them to create a coherent new experience.
