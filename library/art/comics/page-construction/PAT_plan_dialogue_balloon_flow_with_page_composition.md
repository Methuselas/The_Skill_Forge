# Plan Dialogue Balloon Flow With Page Composition

## Pattern Rule
**IF** dialogue must share a comic page with staged image action and still read in the intended order
**THEN** Reserve and route dialogue balloons during page layout so reading order, speaker identity, and image composition work together

## Do
- Place balloons early enough to affect panel composition.
- Order them so dialogue and visual reading paths agree.
- Use tails, position, and differentiated treatment to preserve speaker identity.

## Don't
- Do not bolt balloons onto finished art where they obscure essential action or create ambiguous order.

## Checklist
- Dialogue order is unambiguous.
- Balloon placement does not break the panel’s focal hierarchy.
