# Separate Story Keys From Motion Extremes

## Pattern Rule
**IF** planning an action requires distinguishing poses that explain the story from poses that merely mark outer motion positions
**THEN** Distinguish storytelling keys that explain what happens from motion extremes that define important outer positions or direction changes

## Do
- Plan the story keys needed for intelligibility.
- Add motion extremes required by the physical transition.
- Allow one drawing to serve both roles only when it genuinely does both.

## Don't
- Do not use key and extreme as automatic synonyms.

## Checklist
- The sequence remains understandable from story keys alone, while motion extremes clarify how it moves.
