# Hold Timing Constant And Compare Spacing Profiles

## Practice Task
Animate one simple move several times with identical start, end, path, and duration but different spacing distributions.

## Target Skill
Animate one simple move several times with identical start, end, path, and duration but different spacing distributions.

## Setup
Use a minimal subject or short sequence so the named variable can be compared without polish hiding the result.

## Instructions
1. Fix the endpoints and total frame count.
2. Make an even-spacing version.
3. Make an ease-out/ease-in version.
4. Make an intentionally asymmetric version.
5. Compare perceived speed, energy, deliberateness, and attitude.

## Success Check
- The versions feel meaningfully different even though duration and endpoints are unchanged.

## Common Failures
- Changing the frame count between versions.
- Adding shape changes that hide the spacing comparison.
