# Finish One Animal Head With Explicit and Suggestive Mark Strategies

## Practice Task
Build one animal head to a stable structural state, duplicate that construction, and finish the two versions with deliberately different amounts of explicit description.

## Target Skill
Varying the amount and kind of explicit description while preserving one stable animal-head construction and intended impression.

## Setup
Choose a clear animal-head reference with readable skull type, soft forms, and coat or tonal information. Make one accepted Stage-3 construction first, then duplicate or redraw it twice at the same orientation.

## Instructions
1. State the dominant impression you want both finished studies to preserve.
2. In version A, use a descriptive strategy: allow contour, hatching, or coat direction to make plane turns and structural relief explicit.
3. Keep the marks tied to the actual head volume; use texture as an organizing surface path rather than as a decorative fill.
4. In version B, reduce explicit description. Use selected tonal notes, blank areas, broken marks, and omission so fewer statements imply the same living head.
5. Compare the two versions at thumbnail size. Verify that both still preserve the same skull type, head orientation, soft-tissue relationships, and dominant impression.
6. If the suggestive version becomes generic, restore only the minimum structural cue required. If the descriptive version becomes busy, remove marks that do not add form or emphasis.

## Success Check
- Both finishes preserve the same accepted construction.
- The descriptive version uses explicit marks to organize form rather than merely accumulate texture.
- The suggestive version remains species-specific despite greater omission.
- The intended impression survives in both strategies.
- Each version stops when its statement is complete instead of converging toward the same amount of finish.

## Common Failures
- Changing the underlying head proportions while attempting a different finish strategy.
- Using hatching that follows a lighting pattern but ignores the surface turn being studied.
- Equating suggestion with random missing information.
- Filling every blank area because the drawing feels unfinished rather than because the structure needs clarification.
- Treating one historical artist's handling as the correct style instead of testing the explicit-versus-suggestive decision.

## Notes
Bammes places analytical coat-following modeling beside painterly suggestion to demonstrate that the same understood object can support very different levels of explicit statement. The exercise is not a style-copy assignment. It asks whether structural knowledge is strong enough to survive both more descriptive and more abbreviated finish behavior.
