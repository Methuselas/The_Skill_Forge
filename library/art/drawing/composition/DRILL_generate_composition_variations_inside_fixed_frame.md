# Generate Composition Variations Inside a Fixed Frame

## Practice Task
Choose one simple frame and produce a set of materially different internal subdivisions using only simple lines and areas before introducing recognizable subject matter.

## Target Skill
Judge spacing and whole-picture shape relationships directly, without letting rendering or subject familiarity disguise a weak arrangement.

## Setup
Draw a repeated square or circle at the same size. Keep line type and thickness simple enough that spacing, direction, and enclosed shapes remain the main variables.

## Instructions
1. Make several distinct internal arrangements rather than small cosmetic variations of one idea.
2. Compare the trials as abstract shape-and-space systems and select the strongest whole-picture relationship.
3. Generate a second set of variations from the selected solution instead of treating the first good answer as final.
4. Restore one suppressed variable at a time, such as curves, line-weight change, or a recognizable motif, while preserving the spacing problem as the main target.
5. Transfer the strongest arrangement into a small representational or applied design and check whether the structure survives the added content.

## Success Check
The strongest solutions remain coherent as abstract spacing patterns, differ meaningfully from one another, and still hold together after recognizable content is added.

## Common Failures
- Producing many near-duplicates instead of exploring different organizations.
- Letting a decorative motif carry interest while the underlying spacing stays weak.
- Changing frame, medium, line weight, and subject at the same time so the study target becomes impossible to judge.
- Treating the geometric boundary as a correctness formula instead of a controlled practice condition.

## Notes
The fixed boundary makes the interior relation visible by holding the container constant. Once that relationship is trainable, the same exercise can be escalated without confusing a new aspect ratio with a stretched old solution.

`VAR_dow_carry_one_theme_across_changing_aspect_ratios` changes the container while holding the theme recognizable. Rebuild the internal arrangement for each rectangle and compare what must move, enlarge, shrink, regroup, or disappear.

`VAR_dow_recompose_observed_scene_from_essential_line_skeleton` begins with observation rather than abstraction. Reduce the view to the lines that create its major spaces, then preserve those essential relationships while recomposing secondary facts to fit a new frame.

`VAR_dow_hold_line_skeleton_vary_which_lines_become_masses` keeps the same line scaffold across trials and changes only which lines gain enough width to read as dark masses. Compare the resulting dark-light balances before altering the underlying spacing, so the effect of mass selection stays visible.

`VAR_dow_hold_line_scheme_remap_whole_areas_between_two_values` keeps the frame and line scheme fixed, then changes which enclosed areas become dark or light. Make several materially different two-value organizations so the effect of mass assignment can be judged independently of the spacing scaffold.
