# Compare Animal Skull Types by Cranial-Facial Balance and Load Paths

## Practice Task
Make a comparative page of at least three contrasting mammal skull types, reducing each to the same structural questions before adding species-specific detail.

## Target Skill
Comparing animal skulls as functional structural variants rather than memorized species silhouettes.

## Setup
Use clear skull references for one herbivore, one carnivore, and one anthropoid or other strongly contrasting mammal. Keep the studies small enough to compare side by side.

## Instructions
1. For each skull, separate the cranial capsule from the facial skull and mark their relative size, direction, and overlap.
2. Indicate the orbit, nasal passage, oral/jaw space, and the main zygomatic or cheek architecture before drawing teeth or fine sutures.
3. Mark the jaw pivot and the main branch/process directions that receive chewing forces. Note where ridges or arches enlarge to support muscle attachment or protect openings.
4. Compare eye direction, facial-skull length, nasal development, jaw depth, and cranial mass across the three studies.
5. Write one short structural sentence beneath each skull describing what most distinguishes it from the others.
6. Redraw one skull from memory using only the cranial/facial split, cavities, and load paths; then compare it with the reference and correct the first structural error.

## Success Check
- All skulls are organized by the same comparative questions rather than by unrelated contour recipes.
- Cranial and facial masses remain legible before local detail is added.
- The jaw, cheek arch, orbit, and nasal region have a readable structural relationship.
- The memory redraw preserves the species' main construction even if small details are omitted.
- Differences are described as proportional/functional changes rather than as fixed stylistic labels.

## Common Failures
- Copying the outer contour accurately while leaving the internal architecture unexplained.
- Comparing isolated details without first comparing the whole cranial/facial balance.
- Treating Bammes's representative horse, cow, dog, lion, and ape examples as exhaustive species formulas.
- Adding teeth and sutures before the major cavities and load paths are coherent.
- Correcting the memory redraw only at the silhouette instead of repairing the structural cause.

## Notes
Section 8.1 is comparative by design. Bammes repeatedly sets representative animal types against one another so the artist can recognize a shared mammalian organization and then see each species as a structural variant. This drill preserves that method: compare the same major masses, cavities, and force-bearing routes across types, then use memory reconstruction to test whether the architecture has become an internal image rather than a copied outline.
