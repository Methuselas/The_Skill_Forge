# Construct a Character Head From a Written Description

## Practice Task
Create one head from a character description you write before drawing, then create a second head from a description supplied by someone else. Work from the verbal brief rather than from a portrait reference.

## Target Skill
Translating verbal character cues into one coherent head type instead of attaching isolated feature symbols to a stock face.

## Setup
Use two short written briefs. Let each description include several visible cues such as overall head build, brow or eye setting, cheek fullness or hollowness, nose size or shape, jaw and chin character, and hair distribution. Keep the drawing at a construction level where the head can still be revised cheaply.

## Instructions
1. Read the brief once and separate **large structural cues** from local accessories. Decide first what the words imply about the cranial envelope, facial divisions, jaw, brow, and cheek structure.
2. Establish the cranial ball, facial plane, middle line, brow cross, and viewpoint before drawing detailed features. Preserve one perspective system even when the brief asks for strong exaggeration.
3. Encode the brief through proportion and spacing first: widen or narrow the head, alter the facial divisions, deepen or flatten the brow/eye setting, and change jaw or chin projection as the description requires.
4. Add the named nose, eyes, mouth, hair, beard, or other local cues only after the large head type reads. Make those features inherit the construction rather than forcing the construction to fit them afterward.
5. Compare the result with the words, not with an imagined generic face. If the description depends on hair, wrinkles, or one oversized feature to be recognizable, remove those cues temporarily and strengthen the underlying head type.
6. Repeat from the second person's brief. Do not copy the first solution; rebuild the proportions and construction from the new description.

## Success Check
- The two briefs produce clearly different large head types before cosmetic detail is added.
- Every feature belongs to the same turn, tilt, middle line, and facial plane.
- Structural words such as broad, narrow, heavy-jawed, deep-set, or hollow-cheeked are visible in the construction rather than represented only by contour decoration.
- A viewer can trace the final head back to the written cues without needing a photographic source.

## Common Failures
- Starting with a stock face and adding hair, beard, brows, or wrinkles as labels for character.
- Exaggerating one feature while leaving the cranial and jaw structure unchanged.
- Breaking the centerline or perspective to make a described eye, nose, or jaw more obvious.
- Polishing the first interpretation instead of rebuilding when the large proportions do not match the brief.

## Notes
Loomis presents this as an early invention exercise: after learning the ball, facial plane, spacing, and type variations, write the character first and make the construction answer the words. Having another person supply the second description tests whether the method transfers beyond the artist's habitual face.
