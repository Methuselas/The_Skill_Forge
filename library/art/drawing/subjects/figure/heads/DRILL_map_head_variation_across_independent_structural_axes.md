# Map Head Variation Across Independent Structural Axes

## Practice Task
Build a small reference matrix that compares heads using **two independent structural reads**: the cranial envelope's broad-to-long tendency and the profile facial/dental projection relative to the forehead. Then reconstruct selected heads with local features suppressed so the large relationships must carry the difference.

## Target Skill
Preventing same-face syndrome and improving profile likeness by separating large skull proportion from facial projection instead of treating a head type as one bundled stereotype.

## Setup
Choose at least nine clear head references with varied ages, appearances, and viewpoints. Use references because they show genuinely different individuals, not because of demographic labels. For the structural comparison, ignore hairstyle and do not record ethnicity, ancestry, personality, or other identity categories. Include enough profile or near-profile views to judge facial projection.

## Instructions
1. For each reference, make a tiny construction that contains only the cranial envelope, facial wedge/jaw, centerline, and a simple dental/mouth mass. Leave eyes, nostrils, lips, hair, and decorative character detail unresolved.
2. Judge the **cranial axis** comparatively: is this skull envelope relatively broader/shorter, intermediate, or longer/narrower than the other references? Do not force a numerical cutoff.
3. On profile references, judge the **projection axis** separately by comparing the forehead to the front dental/facial mass while mentally removing the nose from the measurement. Record only relative projection—more upright, intermediate, or more projecting.
4. Arrange the studies as a loose two-axis matrix. If two heads share one axis but differ on the other, keep both; those pairings are the point of the exercise.
5. Pick three cells that differ strongly. Redraw those heads from memory using only the cranial and facial masses. Check whether they remain distinct before local features or hair are added.
6. Return to the references and correct the earliest large-relationship error. If a nominal category fights the observed silhouette, discard the category and keep the observation.

## Success Check
- Several heads remain recognizably different after hair and detailed features are removed.
- Cranial envelope and facial projection can change independently rather than as one locked bundle.
- Profile likeness improves because the forehead-to-dental relationship is checked before the nose contour distracts from it.
- No demographic label, personality assumption, or fixed ratio is used to predict a head's structure.

## Common Failures
- Sorting references by ethnicity or ancestry instead of by visible structural relationships.
- Treating Hogarth's broad/intermediate/long labels or exact ratios as biological classes.
- Assuming a broad skull requires one facial slope, feature set, or forehead shape.
- Letting hair, eyebrows, expression, or surface rendering create all the variation while the underlying head block remains identical.
- Measuring the nose tip as if it defined the facial-projection axis Hogarth is diagramming.

## Notes
The durable lesson in Hogarth's Chapter V is not the historical cephalic taxonomy. It is that **large head variation can be compared along more than one structural dimension**, and that those dimensions should be allowed to combine freely. His own example section explicitly warns against assigning one head form to an entire population. PASS therefore keeps the comparison exercise and rejects the racial/ethnic classification framework.
