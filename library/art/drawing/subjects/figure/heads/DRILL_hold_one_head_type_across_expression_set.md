# Hold One Head Type Across an Expression Set

## Practice Task
Design or choose one clearly constructed head type, then draw that same head through a small set of different expressions. Keep the underlying character identity stable while the mouth, cheeks, eyelids, brows, and other movable tissues change.

## Target Skill
Separating **head identity and construction** from **expression deformation** so a character does not become a different person every time the face moves.

## Setup
Start from one head whose large cranial envelope, jaw, feature spacing, and viewpoint system are already clear. Choose four expressions from Loomis's examples or comparable visible actions, such as a smile, laugh, frown, pout, worry, or anger. Keep a mirror available so you can observe what the facial tissues actually do instead of inventing expression symbols.

## Instructions
1. Draw the neutral construction first. Mark only enough of the cranial ball/facial plane, middle line, jaw, and feature placement to make the head type unmistakable.
2. Before each expression, preserve the same large head proportions and feature locations. Do not redesign the skull, jaw, or spacing just to make the emotion more obvious.
3. Use the mirror to observe the **action** of the mouth corners, cheeks, eyelids, brows, and chin. Look for how the forms bunch, stretch, lift, or compress rather than copying every small wrinkle.
4. Rebuild the expression on the same head. Let the moving flesh deform around the stable head construction and keep paired features coordinated around the middle line when the head turns or tilts.
5. Compare all versions side by side. If one drawing no longer reads as the same person, remove expression detail and repair the large proportions and feature placement before continuing.
6. Repeat any weak expression once from the mirror, looking only for the muscle/form action that was missed rather than adding more lines.

## Success Check
- All expressions still read as the same head type when hair and cosmetic surface detail are ignored.
- The cranial envelope, jaw, and major feature spacing remain stable unless the jaw is intentionally opening as part of the expression.
- The expression is carried by visible changes in the movable facial forms rather than by symbolic wrinkle marks alone.
- Turned or tilted versions keep the expression inside the same head perspective and middle-line system.

## Common Failures
- Changing the jaw width, eye spacing, or skull shape from expression to expression.
- Drawing a stock smile/frown symbol without showing how the surrounding flesh reacts.
- Adding many small wrinkles when the large cheek, mouth, lid, or brow action is still unclear.
- Copying the first eye or mouth mechanically onto the opposite side in a turned head.

## Notes
Loomis presents expression study as practical mileage: learn the facial muscle actions, use the mirror, then develop one type and make several drawings of that same character in different expressions. The drill preserves that sequence while keeping the head-construction work from the preceding Loomis units active underneath the expression study.
