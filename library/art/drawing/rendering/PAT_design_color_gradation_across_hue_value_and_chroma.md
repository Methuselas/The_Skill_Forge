# Design Color Gradation Across Hue, Value, and Chroma

## Pattern Rule
**IF** a passage must change continuously across space
**THEN** define the endpoints and deliberately plan which of hue, value, and chroma change along the path, then interpolate those dimensions together rather than treating the gradation as only a light-to-dark blend
**ELSE** keep a flat or stepped relationship when continuity is not part of the effect.

## Do
- State the start and end color in hue, value, and chroma terms before blending.
- Decide whether each dimension changes linearly, concentrates near one end, or remains comparatively stable.
- Check the midpoint for accidental mud or hue detours caused by uncontrolled mixing.
- Judge the gradation at the scale where it will be seen; a technically smooth blend can still have the wrong perceptual path.

## Don't
- Assume a gradation means value change only.
- Average endpoints mechanically when the intended hue path should curve through another family.
- Smooth away useful structural boundaries merely because adjacent colors differ.

## Checklist
- The endpoints and intermediate direction are intentional in all changing dimensions.
- The gradation reaches the intended midpoint family without accidental neutralization.
- The transition serves the form, atmosphere, or color design rather than existing as generic smoothness.

## Notes
Color gradation is multidimensional. Many natural effects change hue, value, and chroma at the same time, so planning the path before blending is more reliable than correcting an accidental transition afterward.
