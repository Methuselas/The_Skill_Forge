# Map a Working Palette With Pairwise Mixture and Value Charts

## Practice Task
Build a controlled chart of the working palette by mapping each parent color through a value string and then pairing each parent with every other palette color while keeping the chosen parent visibly predominant.

## Target Skill
Learn the actual mixture behavior of a selected palette: directional hue shifts, value/chroma changes, family predominance, duplicate routes, and the effect of lightening across related mixtures.

## Setup
Choose the palette that will actually be used. Prepare a consistent chart structure that can compare the parent colors, their pairwise mixtures, and the same small set of value steps. For digital or generated work, use a fixed interpolation/compositing method so the chart measures one repeatable behavior.

## Instructions
1. Chart each palette color alone through the chosen value string so its own lightening path is visible.
2. Choose one palette color as the dominant parent and mix it separately with every other palette color while keeping the parent visually predominant.
3. Carry each resulting pair through the same value steps instead of changing the scale from row to row.
4. Repeat until every palette color has served as the dominant parent.
5. Index each mixture perceptually as well as procedurally: identify the hue family that actually predominates, its directional lean, and its value instead of remembering only the ingredient names.
6. Compare the matrix for useful mixture neighborhoods, unexpectedly large hue/chroma shifts, nearly duplicate routes, and colors whose identity becomes clearer or weaker when lightened.
7. Use the completed chart as a search map during later target matching, then let the real target and surrounding context overrule the chart when necessary.
8. Recalibrate affected rows when the working palette, interpolation method, compositing behavior, or material set changes materially; similar names do not guarantee similar behavior.

## Success Check
- Every parent has been compared through a consistent set of pairwise and value relationships.
- The chart can suggest a plausible starting neighborhood for a target without pretending to be the final answer.
- Mixtures can be recognized by perceptual family, directional lean, and value rather than only by recipe.
- A changed palette triggers targeted recalibration instead of inherited assumptions.

## Common Failures
- Randomly sampling attractive mixtures without completing a comparable matrix.
- Letting the secondary color overpower the intended dominant parent, which makes rows incomparable.
- Changing value steps or interpolation behavior from one row to another.
- Memorizing pigment or swatch names while failing to learn what the mixtures actually look like.
- Treating the chart as a formula that overrides the target color's real context.

## Notes
The chart is a calibration tool for a particular working palette. Its value is systematic coverage: pairwise neighborhoods and value paths become familiar before the pressure of a picture problem. The matrix narrows later search and reveals medium-specific behavior, but it remains evidence rather than a substitute for contextual color judgment.
