# Branch One Fact Set into Distinct Visual Concept Families

## Practice Task
Build one questionnaire or fact pool for an ordinary subject, then turn that same evidence into at least two genuinely different visual concept families before choosing camera or composition.

## Target Skill
Breaking concept fixation by changing the underlying pictorial premise rather than disguising one idea with different viewpoints, poses, or surface treatments.

## Setup
Choose one product, story premise, subject, or brief and build a concise fact pool for it. Mark at least two different clusters inside that material, such as practical use versus emotional consequence, problem versus benefit, sensory property versus human action, or origin versus outcome.

## Instructions
1. Keep the factual pool fixed for the entire exercise.
2. Write one sentence for the visual premise suggested by each selected cluster without describing camera, crop, rendering, or color style.
3. Make several tiny roughs for the first premise using only enough drawing to prove the idea.
4. Make several tiny roughs for the second premise while preserving the same underlying facts.
5. Reject any pair whose only difference is viewpoint, prop placement, color, or pose adjustment; return to the fact clusters and change the conceptual question instead.
6. Compare the families for relevance to the assignment, visual clarity, and conceptual range.
7. Repeat with another subject until branching away from the first obvious interpretation becomes routine.

## Success Check
- Two or more families answer different conceptual questions while using the same factual source.
- The families remain recognizably different even if camera and rendering differences are ignored.
- At least one useful route was not the first obvious interpretation.
- The learner can identify which fact cluster generated each family.

## Common Failures
- Adding unsupported facts merely to force variety.
- Calling a new viewpoint or palette a new concept when the underlying proposition has not changed.
- Rendering one family much farther than the others and confusing finish with concept quality.
- Abandoning the original evidence instead of discovering another relationship already inside it.

## Notes
Loomis demonstrates that one questionnaire can yield substantially different idea families from the same subject. Stage 0 thumbnails search composition after a proposition exists; this drill deliberately branches the proposition itself before that commitment.
