# Calibrate a Scene From One Figure

## Practice Task
Use one correctly constructed figure as the initial scale and direction reference for a small scene containing another object and two additional figures.

## Target Skill
Carry one solved scene field across figures and objects instead of resizing or reorienting each addition independently.

## Setup
Draw one simple figure in depth with a clear ground relationship. Keep the scene sparse enough that the perspective scaffold remains readable.

## Instructions
1. Choose useful body landmarks or planes that communicate height, ground contact, and dominant spatial direction.
2. Extend those relationships into a minimal shared perspective scaffold.
3. Add one object whose size is judged relative to the first figure.
4. Add a second figure at another depth while preserving corresponding height relationships on the same ground condition.
5. Add a third figure with a different body orientation but keep it inside the same scene field.
6. Check the result against the formal eye level and vanishing directions; correct the figure-derived scaffold if those disagree.
7. Remove unnecessary guides and verify that all additions still feel like one spatial world.

## Success Check
- The object and added figures share believable relative scale with the first figure.
- Different local body orientations still obey the same viewer and scene field.
- Ground contacts and height relationships remain coherent through depth.
- The scene does not require a new independent grid for each object or figure.

## Common Failures
- Treating the first figure as a substitute for establishing eye level and vanishing behavior.
- Scaling later figures by intuition after the shared field has been solved.
- Rotating an added figure by changing the scene's perspective instead of the figure's local orientation.
- Preserving a bad figure-derived guide when formal perspective exposes the error.

## Notes
The figure is a calibration entry point, not a replacement for perspective. Once the shared field is established, the field becomes the authority for every later figure and object.
