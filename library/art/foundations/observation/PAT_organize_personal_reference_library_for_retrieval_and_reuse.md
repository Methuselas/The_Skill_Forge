# Organize Personal Reference Library for Retrieval and Reuse

## Pattern Rule
**IF** reference, studies, notes, photographs, clips, or production evidence are accumulating across repeated art and animation work
**THEN** organize the collection around reliable retrieval and future reuse so relevant evidence can be found when the same kind of problem returns
**ELSE** keep the collection lightweight until its size or recurrence makes retrieval a real constraint.

## Do
- Keep useful material generated by your own practice—notes, production journals, sketchbooks, photographs, moving-image studies, and other firsthand evidence—alongside relevant external sources.
- Let the collection grow from actual recurring interests, subjects, and production problems rather than trying to build an exhaustive archive in advance.
- Use consistent classification and naming conventions for digital material so subject, action, source, or other useful search terms remain recoverable later.
- Preserve a practical range of source types when they answer different questions: firsthand observation, books, still images, moving images, drawings, notes, and other appropriate media.
- Periodically test retrieval by trying to find material for a real current problem; reorganize when the storage scheme repeatedly hides useful evidence.
- Keep material whose future value is plausible when storage cost is low, especially original observations and production records that cannot easily be recreated.

## Don't
- Do not confuse collecting with research; a large archive has little value if it cannot answer a concrete question or be found again.
- Do not let one convenient source channel become the entire reference library when other evidence types would answer different aspects of the problem better.
- Do not use vague or inconsistent filenames that make later retrieval depend on memory of where a file was stored.
- Do not retain every item indiscriminately when duplication and clutter make the useful material harder to retrieve.
- Do not treat the library as static; its structure may need to change as the practice develops and new recurring problems appear.

## Checklist
- Material can be found by a meaningful subject, action, source, or project cue without relying on memory alone.
- Original practice evidence is preserved alongside selected external reference.
- Naming and classification are consistent enough to support later search and reuse.
- The collection contains more than one useful evidence type where the practice genuinely needs them.
- A current production or study question can retrieve relevant material quickly enough to make the library operationally useful.

## Notes
Webster treats a personal reference library as a long-term working resource built alongside practice. Its value comes not only from accumulation but from being specific to the artist's recurring interests and from remaining accessible: notes, journals, sketchbooks, photographs, moving images, books, and other sources only become reusable evidence when storage, classification, and naming allow them to be found again. The durable Art rule is retrieval over hoarding and diversified evidence over dependence on one convenient channel.
