# Create Task-Specific Reference When Available Material Misses the Required Action

## Pattern Rule
**IF** existing reference does not show the movement, circumstance, subject relationship, or mechanical detail that materially controls the action you need to solve
**THEN** create new reference specifically for that question, choosing the least complicated capture method that can reveal the missing evidence
**ELSE** use the available reference and avoid making a custom capture merely for novelty.

## Do
- State the missing evidence before capturing anything: timing, support, balance, contact, grip, trajectory, acting choice, or another concrete action question.
- Evaluate existing reference for relevance, reliability, original purpose, and fit to the current question before deciding that new capture is necessary.
- Prefer existing/secondary evidence when it answers the question well enough; create primary material when tighter control or specificity materially changes the answer.
- Balance the value of custom reference against time, cost, access, practicality, and safety rather than treating firsthand research as automatically superior.
- Choose a method suited to the evidence: direct observation, directed performance, embodied rehearsal, analytical drawing, still photography, sequential photography, or recorded motion.
- Recreate the relevant circumstance closely enough that the reference answers the actual problem rather than a nearby generic one.
- Capture only as much material as is needed to resolve the question, then return to the artwork or animation.
- Treat custom reference as evidence to analyze and adapt, not as a command to reproduce every surface detail literally.

## Don't
- Do not force a generic library clip to stand in for a materially different action just because it is convenient.
- Do not assume widely available reference is accurate or fit for purpose merely because it is easy to find.
- Do not reject useful secondary material simply because you did not create it yourself.
- Do not pursue hazardous, inaccessible, or disproportionately expensive primary research when a safer secondary source answers the practical question.
- Do not build an elaborate capture setup when a simpler observation or rehearsal would answer the same question.
- Do not assume one performer, camera angle, or take exhausts the possible solutions when the task depends on character, body type, environment, or intent.
- Do not preserve irrelevant details from the reference when transferring the useful mechanics to a different subject.

## Checklist
- The exact missing action evidence has been named.
- The chosen capture method can reveal that evidence.
- The setup reproduces the important mechanical or behavioral constraint.
- The resulting reference changes or confirms a concrete animation or drawing decision.
- Unrelated visual details are not being copied merely because they were captured.

## Notes
Webster argues that a large reference collection can still fail to answer a particular animation problem. When the available material misses the required action, the useful response is not to improvise from memory or force an unsuitable substitute but to make reference for the exact question. The method should follow the information need rather than become an end in itself. Primary-versus-secondary research sharpens the routing decision: existing material is often the fastest sensible answer, but it must be checked for relevance, reliability, and original purpose; custom material earns its cost when tighter control or specificity matters enough to change the animation decision.
