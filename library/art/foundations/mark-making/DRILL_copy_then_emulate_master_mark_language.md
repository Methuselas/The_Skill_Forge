# Copy Then Emulate a Master's Mark Language

## Practice Task
Study one drawing by copying its mark behavior, then draw a different subject from life or reference while borrowing the same mark-making logic.

## Target Skill
Recognizing how a particular artist's stroke length, pressure, pace, connection, and rhythm create a transferable mark-making system.

## Setup
Choose a master drawing with clearly legible marks and use a reasonably similar drawing medium for the copy. Prefer an original-size or highest-fidelity reference when fine line decisions matter. Prepare a new subject for the emulation pass.

## Instructions
1. Copy a small passage while attending to how the marks were likely made: length, direction, connection, pressure change, speed, edge, and rhythm.
2. When placement differences are obscuring the mark study, register the reference beneath a transparent or overlay layer and reproduce a small passage directly. Use the registration to remove placement error from the exercise so you can compare line thickness, taper, connection, omission, spacing, and edge decisions themselves.
3. Compare the behavior of your marks with the source rather than judging only whether the depicted object looks similar.
4. Put the master drawing aside or at a secondary reference position and draw a new subject using the borrowed handwriting.
5. Note which mark behaviors transfer and which collapse when they are no longer tied to the copied shapes.
6. Repeat later with a markedly different artist rather than settling permanently into one borrowed manner.
7. If the source is a reduced reproduction, infer the original mark scale from its structural role and overall drawing size instead of literally copying the reproduced line width.
8. Separate observable surface behavior from speculative hidden procedure: emulate stroke breadth, edge behavior, economy, layering, or other visible logic without claiming the artist's exact tools, speed, materials, or sequence unless independent evidence actually establishes them.

## Success Check
- The copied passage matches observable stroke behavior such as length, direction, taper, connection, pressure change, spacing, edge, or rhythm rather than merely reproducing the subject contour.
- If registration or an overlay was used, it removes placement error from the comparison instead of turning the exercise into a tracing-accuracy test.
- The second drawing applies recognizable mark logic to genuinely new forms without tracing, repeating the source composition, or borrowing its subject arrangement.
- At least one mark behavior that transfers and one that weakens or collapses on the new subject are named from the two drawings.
- A reduced reproduction is interpreted by structural role rather than copied at its printed line width when that would turn broad marks into finicky micro-marking.
- Claims stay with visible mark behavior; speculative tool, speed, material, or sequence stories do not count as evidence of emulation.

## Common Failures
- Copying subject contours while ignoring the physical character of the strokes.
- Treating emulation as permanent style adoption.
- Choosing a different medium whose behavior makes the target mark language impossible to test.
- Turning a broad economical source into finicky micro-marking because the reference was reproduced smaller than the original.
- Treating an overlay copy as a placement exercise instead of using it to isolate mark-making decisions.

## Notes
Dodson separates copying from emulating: copying gives a felt understanding of another artist's handwriting, while emulating tests whether that understanding can survive on a new subject.

`VAR_martin_audition_multiple_inking_systems_on_one_fixed_drawing` uses the opposite control for a finishing study: keep the drawing fixed and deliberately change the coordinated inking system. Compare versions in which form is carried primarily by black masses and restrained contour, by strong contour with sparse feathering, by dense form-wrapping line transitions, or by a dead-weight exterior/interior hierarchy. The point is to identify what each system changes and why one fits the source better, not to collect named styles.

`VAR_martin_compare_multiple_finishers_on_identical_pencils` turns the same fixed-source setup into an attribution study. Across several independent finishes, first mark what the pencils keep invariant, then classify each finisher's interventions as preserved, clarified, amplified, simplified, corrected, or overrode. Judge whether each departure helps the source communicate or merely replaces it with a habitual finish. A stronger repeat uses several drawings from the same penciller so recurring source signals can be distinguished from one-page accidents before making a new pass at an explicitly chosen intervention level.

Finished work supports conclusions about visible mark behavior much more strongly than it supports claims about hidden historical procedure. Treat exact tool choice, speed, and sequence as unknown unless another source establishes them; transfer the observable logic instead.
