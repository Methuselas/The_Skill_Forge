# Reframe Same Scene To Change Narrative Message

## Pattern Rule
**IF** the underlying event stays the same but the image must communicate a different narrative emphasis or interpretation
**THEN** Change what the same scene means by altering selection, crop, scale, viewpoint, emphasis, and omission without requiring different underlying events

## Do
- Hold the basic scene facts constant.
- Audition alternate framings that foreground different relationships or information.
- Choose the version whose visual hierarchy states the intended narrative message.

## Don't
- Do not assume one “correct” framing exists for a scene.

## Checklist
- Different framings of the same setup produce measurably different story reads.

## Notes

Keep a short list of invariant scene facts while auditioning crops so the comparison isolates composition rather than quietly rewriting the event. If a candidate needs a new action or prop to produce its message, it is a different beat, not merely a different framing.
