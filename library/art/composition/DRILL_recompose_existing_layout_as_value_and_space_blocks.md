# Recompose an Existing Layout as Value and Space Blocks

## Practice Task
Reduce an existing page, ad, cover, poster, interface, or other multi-unit layout to a few simple blocks and lines, then build several new arrangements from the same required units.

## Target Skill
Reading illustration, text, product, value masses, and open space as one composition whose hierarchy can be changed through scale, spacing, grouping, and placement.

## Setup
Choose one existing layout. Work small enough that words and image details cannot be copied literally. Limit the study to a few values plus simple blocks for the illustration, text, title, product, borders, and empty space.

## Instructions
1. Make one tiny abstract map of the source layout's large value and spacing pattern.
2. Identify which units are required and which small fragments can be ignored for the exercise.
3. Create several new arrangements by moving, resizing, grouping, separating, or simplifying the same required units.
4. Deliberately vary white space, dominant mass, and the relationship between illustration and surrounding copy.
5. Compare the versions for emphasis, balance, readability, breathing room, and eye path.
6. Return to the original and identify which structural decisions were essential and which were only one possible solution.
7. Repeat with a layout whose density is very different so the exercise does not collapse into one favorite arrangement.

## Success Check
- The original can be explained as a pattern of masses and spaces without relying on subject detail.
- Alternative arrangements remain functional with the same required units.
- At least one redesign changes hierarchy through spacing or value rather than decoration.
- The illustration is judged as part of the whole field instead of as an isolated rectangle.

## Common Failures
- Copying typography, drawing detail, or brand styling instead of reducing the source to structure.
- Adding new content simply to make a version look different.
- Making every arrangement use the same dominant mass and white-space pattern.
- Polishing a layout before its large value and spacing relationships have been compared.

## Notes
Loomis recommends reducing existing magazine layouts to simple value and space units and rearranging them to develop a coordination sense. The exercise preserves that structural practice without turning historical ads into templates to imitate.
