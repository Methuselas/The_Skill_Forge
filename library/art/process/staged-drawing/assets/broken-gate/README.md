## Architecture demonstrated

Universal Drawing now ends at **Stage 4 — Finished Pencils**. Ink, Color, Paint,
Manga/B&W finish, and other medium-specific operations are downstream workflows.

Registered successor operations require both canonical predecessor identity and
actual accessibility of that exact artifact to the native image tool when an edit
or reference source is required. If exact source access is unavailable, fail
closed and recover/re-upload the exact accepted artifact. A re-upload restores the
same canonical predecessor and lockset without reapproval.

**Loss of edit-target access does not authorize visual reinterpretation.**
