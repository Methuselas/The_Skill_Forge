# Develop a Scene Through Registered Successors

## Pattern Rule
Develop every important object in an accepted scene from its exact ratified predecessor representation. Later visual operations add only currently authorized information to the same artifact instead of independently regenerating a similar scene from the original verbal brief.

## Do
- Register the actual accepted predecessor before adding information. The verbal brief remains constraint/context; it is not a substitute visual source once an accepted artifact exists.
- Apply continuity scene-wide to figures, weapons, props, architecture, terrain, vehicles, signs, pipes, cables, effects, and other compositionally important objects.
- Preserve each object's solved camera-space location, apparent scale, orientation, perspective, overlap order, attachment/contact relationships, topology/member count, major proportions, near/far relationship, and approved path/leading-line geometry. Preserve composition-level negative-space shapes and major environment masses too.
- Carry an additive approved-state lockset forward: composition approval freezes camera/framing/placement/scale/major environment relationships; structural approval freezes registered geometry/contacts/perspective; later approvals freeze only the new decisions they own.
- Develop representation rather than replacing identity: action lines become body masses; weapon axes/blocks become weapon volumes; wall planes become architectural masses; pipe centerlines become cylinders.
- **Pass the exact-predecessor accessibility gate before any successor operation that depends on image editing/reference continuity.** Confirm two separate truths: (A) the canonical predecessor identity is known, and (B) that exact canonical artifact is actually available to the native image tool as an edit/reference source.
- If (B) fails, **fail closed**. Recover or request a re-upload of the exact accepted predecessor. A user re-upload restores access to the same canonical artifact with the same inherited lockset; it does not create a new composition and does not require reapproval.
- Use true edit/reference/underdrawing continuity whenever the host exposes it. Supply the approved predecessor as the source rather than making a fresh generation from prose.
- Keep canon and composition authority fixed while visual resolution increases. Large pixel/style changes are permitted only when they do not alter frozen decisions. Distinguish **pixel change** from **decision change**.
- Verify successor reducibility: reducing the successor to the predecessor's information level should recover the same accepted arrangement and approved lockset.

## Don't
- Do not treat figures as the only objects that need registered continuity.
- Do not restart later artifacts from the original prose prompt when an accepted predecessor exists.
- Do not reconstruct a predecessor from prose merely because PASS knows which image was canonical. Canonical-state knowledge does not grant native edit access.
- Do not substitute a rejected artifact, an earlier artifact, or a visually similar near-regeneration when the exact required predecessor cannot be accessed.
- Do not silently move, rotate, rescale, reconnect, multiply, delete, or materially redesign a registered object whose owning decision is already ratified.
- Do not invent major downstream inventory that has no predecessor representation; return to the operation that should have introduced it.
- Do not claim exact tool lineage when the host does not expose it.
- Do not let increased detail loosen canon, composition, or structural locks.

## Checklist
- Exact accepted predecessor identified.
- Exact accepted predecessor actually exposed to the native tool when the requested operation requires edit/reference continuity.
- If access was missing, generation stopped and exact-artifact recovery/re-upload was requested instead of reconstruction.
- Every important scene object has a registered predecessor representation.
- Camera, crop, placement, perspective, overlaps, contacts, major negative spaces, leading/path geometry, and environment masses remain recoverable.
- No major object appears downstream without an upstream predecessor.
- Successor reduces back to the accepted predecessor rather than merely resembling the original verbal request.

## Notes
This is the scene-wide generalization of onion-skin continuity. The figure-specific onion-skin AP remains useful for articulated figure construction, but weapons, buildings, props, and environments require the same predecessor discipline.

The Broken Gate sequence is the canonical positive lineage for this rule. Its failed Stage 4 tightening attempt is the negative accessibility precedent: PASS retained the accepted Stage 4 identity, but the native editor did not reliably expose that exact image as an editable source. A highly similar reconstruction did not count as a valid local edit.

The compact rules are: **develop the accepted artifact forward; do not restart from the prompt and hope for resemblance** and **loss of edit-target access does not authorize visual reinterpretation.**
