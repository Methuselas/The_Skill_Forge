# Scan Single Object for Light-Induced Color Variation

## Practice Task
Choose an object or surface that would normally receive one simple local-color label and map the visible color variation distributed across it while holding the scene and lighting fixed.

## Target Skill
Learning to see one object as a field of different visible colors produced by illumination, shadow, reflection, and perceptual context rather than as one unchanged local-color swatch.

## Setup
Use a reference in which one object occupies enough area to contain meaningful light, shadow, and reflected-color variation. Keep the full image available, but prepare a way to inspect small regions with reduced surrounding context.

## Instructions
1. Inspect the object as a whole and record its expected or nominal local-color description.
2. Isolate a small region and sweep that inspection systematically across the same object rather than sampling only one suspicious patch.
3. Locate the lightest and darkest visible regions.
4. Locate the highest- and lowest-chroma regions, including near-neutral areas that the local-color label might tempt you to ignore.
5. Identify meaningful hue departures from the nominal local color.
6. Describe the strongest departures by hue, value, and chroma before trying to explain them.
7. Map those departures back onto plausible causes such as direct light, shadow, reflected light, neighboring color, or material response.
8. Restore the whole image and verify that the recovered distinctions still make sense in context rather than treating the isolated samples as final truth.
9. Compare the final variation map against the initial one-color assumption and note which regions would have been flattened or miscolored if the local-color label had been followed literally.
10. Repeat with different materials and lighting arrangements so the exercise trains perception rather than one object class.

## Success Check
- The final map contains meaningful within-object variation rather than one nominal hue with only generic light/dark changes.
- Neutral, shifted-hue, and low-chroma regions are allowed when the observation supports them.
- The identified variation can be related plausibly to illumination, reflection, material response, or perceptual context.
- Isolated observations still work after the full surrounding context is restored.

## Common Failures
- Sampling only one patch and assuming it represents the whole object.
- Forcing every region back toward the object's remembered local color.
- Treating every difference as a hue change while ignoring value and chroma.
- Inventing a physical light explanation for a shift caused mainly by simultaneous contrast or adaptation.
- Accepting isolated samples without checking how they read in the whole image.
- Changing the lighting or reference between samples, which turns the rep into a different exercise.

## Notes
This drill holds the scene fixed and searches for variation across one object at one moment. That distinguishes it from comparing the same subject across changing light. The useful rep is to move from categorical expectation to localized observation, then back to whole-context judgment: scan, describe, explain, restore.
