# Match Target Color by Hue, Value, and Chroma Correction

## Practice Task
Choose target colors from references and converge on each one through repeated hue, value, and chroma diagnosis rather than by relying on a color name or uncontrolled trial and error.

## Target Skill
Learning to convert an observed color into controllable dimensions, identify the dominant mismatch in a candidate, and make the smallest useful correction before checking for secondary drift.

## Setup
Prepare several target colors from photographs, paintings, or generated references together with a way to produce adjustable candidate colors. Keep each target's surrounding colors available for the final context check.

## Instructions
1. Select one target and describe it before matching: identify its approximate hue family, relative value, and relative chroma.
2. When a calibrated working-palette chart exists, use it to choose the most promising parent mixture and approximate value neighborhood before beginning correction; the actual target and surrounding context remain authoritative.
3. Inspect the available starting colors and choose a source set whose hue biases move toward or bracket the target rather than fighting it from the outset.
4. Produce an initial candidate without trying to solve every dimension at once.
5. Compare candidate and target and name the largest current error: wrong hue direction, too light or dark, or too vivid or neutral.
6. Make one controlled correction aimed primarily at that error. Avoid simultaneous large changes to all three dimensions. When value is the dominant error, choose the lightening or darkening route by the collateral hue/chroma shift it is likely to introduce rather than assuming every value adjustment is neutral. When chroma is the dominant error, move deliberately toward an opposing/neutral influence to reduce chroma or back toward the parent hue to restore it, rather than introducing unrelated colors.
7. Recompare the candidate and target from the beginning. Check hue, value, and chroma again because the correction may have introduced secondary drift. After a value correction, this full recheck is mandatory: if the method preserved value but dulled chroma or shifted hue, choose a less disruptive route on the next pass.
8. If corrections repeatedly lose chroma or take an indirect hue detour, test whether the source selection is structurally wrong and restart from a source set better aligned with the target instead of endlessly repairing the mixture.
9. Repeat the diagnose-correct-recheck loop until no remaining mismatch is important enough to damage the intended use.
10. Restore the candidate beside the target's surrounding colors and judge it again. If the context shifts the apparent match, make the smallest contextual correction that preserves the intended relationship.
11. Repeat with targets from different hue families, values, and chroma levels so the procedure does not become tied to one palette.

## Success Check
- Each correction is justified by a named hue, value, or chroma error rather than a vague statement that the color looks wrong.
- The largest mismatch usually decreases after each pass without unnecessary drift in the other dimensions.
- Descriptive color names are translated into workable dimensional estimates instead of being treated as recipes.
- The final candidate remains acceptably matched when returned to the color context in which it will actually be judged.

## Common Failures
- Changing hue, value, and chroma together so strongly that the cause of improvement or failure becomes impossible to identify.
- Using a familiar label such as beige, mauve, or brick red as though it specified one exact color.
- Correcting the first visible error and assuming the other two dimensions stayed unchanged.
- Treating white, black, or any chromatic lightener/darkener as a value-only control when it also changes chroma or hue.
- Treating chroma correction as random color addition instead of a controlled neutralization/reintensification path, or neutralizing all the way to gray when the target only needs a restrained chromatic neutral.
- Accepting an isolated swatch match without restoring the surrounding colors that can alter its apparent hue, value, or chroma.
- Chasing microscopic differences that do not matter to the image instead of stopping once the relationship is fit for purpose.
- Treating a structurally poor source selection as a correction problem and repeatedly neutralizing the mixture instead of restarting from better-aligned source colors.

## Notes
Target matching becomes tractable when the color is described as coordinates rather than a name. A vague label can cover many different mixtures, but an estimate such as red-violet, light, and low-chroma indicates what kind of correction to attempt. The useful practice is a closed loop: describe, compare, identify the dominant error, correct it, and then diagnose again because every adjustment can alter more than the intended dimension. Value corrections deserve special scrutiny: a route that reaches the right lightness can still be the wrong correction if it needlessly sacrifices chroma or pulls the hue away from the target. Chroma corrections likewise work best as a controlled path: move toward an opposing influence only as far as needed, or back toward the parent hue when the candidate has become too neutral, then recheck value as well as hue.

A calibrated pairwise palette chart can narrow the initial search by locating a promising parent family and value neighborhood before the normal hue/value/chroma correction loop begins. The chart is a starting map, not a substitute for judging the target in context.
