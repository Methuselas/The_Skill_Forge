# Isolate Hue, Value, and Chroma in Matched Color Studies

## Practice Task
Use one simple fixed line design to make matched color studies that change hue, value, and chroma separately before combining those dimensions again.

## Target Skill
Learning to recognize what each major color dimension contributes by controlling the other variables closely enough for direct comparison.

## Setup
Choose a simple line design with several enclosed areas. Prepare enough small copies to make a hue set, a value set, a chroma set, and several recombined color schemes. Use any color medium that allows reasonably repeatable mixtures or swatches.

## Instructions
1. Make a **hue set** in which the major difference from version to version is hue identity; keep relative value and chroma as comparable as the medium allows.
2. Make a **value set** within one hue family, stepping the same hue through clearly different light, middle, and dark relationships while avoiding unnecessary chroma shifts.
3. Make a **chroma set** in which hue and value remain substantially stable while the color moves from vivid toward neutral in several clear steps.
4. Place each set side by side and identify accidental drift: a hue test that also became much darker, a value test that changed hue family, or a chroma test that changed both lightness and saturation.
5. Correct enough drift that the intended variable can actually be compared; precision is useful only to make the relationship legible, not to create laboratory measurements.
6. Recombine the dimensions in several small versions of the design, varying hue choices, value distribution, chroma distribution, and the amount of area each color occupies.
7. Compare the recombined versions as whole designs and identify which isolated discoveries remain useful once the colors interact again.

## Success Check
- Hue, value, and chroma changes can be identified correctly in the matched sets without relying on labels.
- Each isolated set changes one dominant variable while keeping the other two stable enough for useful comparison.
- The final schemes differ in controlled, intelligible ways rather than through uncontrolled mixture drift.
- The exercise ends with whole-color judgments; the scales and matched tests do not become rigid formulas for finished work.

## Common Failures
- Letting all three color dimensions change at once and then guessing which one caused the effect.
- Chasing exact numerical equality so aggressively that the exercise becomes measurement practice instead of visual training.
- Treating maximum chroma or strongest hue opposition as automatically superior.
- Finishing the isolated scales without recombining them into an actual design problem.

## Notes
Dow's sequence makes color analysis operational by removing variables temporarily: hue exercises suppress value and intensity differences, value exercises compare light-dark relations within hue families, and intensity exercises move a hue from bright toward gray while holding value steady. The final step recombines those dimensions and considers their distribution in the design. This practice preserves that progression while treating exact scales as temporary learning aids rather than universal color standards.


`VAR_dow_increase_palette_complexity_one_hue_at_a_time` adds a palette-complexity ladder after the hue/value/chroma isolation work. Begin with neutrals plus one hue, expand that hue across useful values, then introduce a second and only later a third hue while keeping the established value relationships readable. The point is to make each added hue earn its place; stop increasing palette complexity when the extra color no longer improves the design.
