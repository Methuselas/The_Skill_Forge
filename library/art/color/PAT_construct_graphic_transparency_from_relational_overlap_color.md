# Construct Graphic Transparency From Relational Overlap Color

## Pattern Rule
**IF** two flat colored shapes must read as passing through one another rather than as one simply covering the other
**THEN** design the overlap as a plausible relational middle that visibly belongs to both parent colors, using hue, value, and chroma so the intersection reads as color interaction instead of an unrelated third patch
**ELSE** preserve a clearer parent/overlap separation when stable front-back occlusion is more important than transparency or spatial ambiguity.

## Do
- Establish the two parent colors clearly enough that the viewer can compare each one with the overlap.
- Build the overlap from a visible relationship to both parents: it may sit between them in hue, value, chroma, or a combination rather than matching either parent unchanged.
- Judge the overlap together with both surrounding shapes; the transparency illusion is relational and weakens when the intersection looks like an arbitrary independent color.
- Use repeated transparent overlaps deliberately when fluctuating or ambiguous planar depth is part of the design.
- Recheck which shape appears in front after changing the overlap, because a plausible mixed intersection can weaken or reverse an otherwise obvious occlusion order.

## Don't
- Treat physical glass, water, or translucent material rendering as the same problem; those require light, reflection, transmission, thickness, and environment cues.
- Reduce graphic transparency to lowering software opacity without checking the resulting hue/value/chroma relationship.
- Choose an overlap color solely because it is attractive if it no longer appears causally related to both parent shapes.
- Use an ambiguous middle when the composition requires an unmistakable front-back order.

## Checklist
- Both parent colors remain identifiable around the intersection.
- The overlap appears related to both parents rather than as an independent pasted color.
- The intended transparency or depth ambiguity survives at the final viewing scale.
- If clear occlusion is required, the overlap does not accidentally flatten or reverse the intended order.

## Notes
Graphic transparency is a designed color relationship, not necessarily a simulation of a physically transparent substance. The useful cue is that the shared region looks like an interaction between the two parent planes. Because that interaction changes boundary strength and front-back reading, the same device can either enrich layered space or create unwanted spatial ambiguity.
