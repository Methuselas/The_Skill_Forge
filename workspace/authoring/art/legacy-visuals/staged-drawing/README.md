# Legacy Staged-Drawing Visuals

Source-only authoring history relocated from the active staged-drawing runtime
asset directory during Drawing Cleanup Pass 3 on 2026-08-21.

These files are preserved as historical evidence or possible future craft-specific
reference material. They are **not current universal Drawing stage authority** and
must not be copied back into an active release merely because they once appeared
in the staged-drawing module.
