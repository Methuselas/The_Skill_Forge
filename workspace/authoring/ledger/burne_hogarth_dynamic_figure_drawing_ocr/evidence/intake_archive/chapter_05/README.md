# PASS — Hogarth Chapter 5 Targeted PASS

This package contains a **candidate-only** PASS extraction for Chapter 5 of Burne Hogarth's *Dynamic Figure Drawing*.

Disposition: **Targeted PASS / reinforcement-heavy**.

Core extraction:
- one Pattern for validating foreshortened limb reach from joint pivots;
- one correction Drill for repairing wonky foreshortened limbs;
- one Chapter 4 width-control patch proposal;
- Chapter 5 AP changes held until Chapter 6.

The supplied book page images are not redistributed here. Source locators and hashes are recorded in the reading receipt.
