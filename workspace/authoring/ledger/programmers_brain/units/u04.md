## Notes

Placement: all five retained objects went to `foundations/code-comprehension`
alongside the u01-u02 material rather than to the new
`foundations/deliberate-practice` topic. Everything here governs reading a piece
of code that is in front of you now — which is exactly what that topic already
holds — whereas deliberate-practice covers building knowledge for later. The one
u04 candidate that belonged on the practice side went there as a variant on the
flashcard drill.

Two collisions were checked and resolved differently. `PAT_diagnose_source_of_code_confusion`
(u01) classifies confusion as missing knowledge, missing information, or exhausted
processing capacity; the new load split subdivides only the third of those into
removable and irreducible, which is a downstream decision rather than a competing
method, so it is `new` and linked `related_to`. `PAT_externalize_intermediate_state_when_tracing`
(u01/u02) already governs writing intermediate values into a trace table; the
state-table procedure is a fuller method for that same pattern, so it landed as a
drill that `teaches` it rather than as a second pattern making the same claim.
