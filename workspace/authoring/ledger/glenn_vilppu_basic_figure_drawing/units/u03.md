The complete Box Forms chapter was read and visually checked. Vilppu's use of the box differs from a rigid block mannequin: the box supplies corners, receding planes, and a clear spatial logic, then can be rounded, bent, twisted, or combined so that action remains primary.

## Delta map

- SPECIALIZES — Stage 2 with animated box logic: corners clarify space, but gesture remains in control.
- DIFFERENTIATES FROM LOOMIS — Loomis squares rounded form into editable planes; Vilppu uses box logic as a temporary spatial aid that can itself bend and regain organic life.
- REINFORCES — freehand perspective, rotating boxes, box mannikins, and primitive choice as tool rather than rule.
