# Patch Proposal — Use an Underlay to Lock POV and Large Volumes, Then Return to Drawing

**Target:** `AP_construct_a_shared_scene_perspective_field`

**Disposition:** candidate patch proposal only; target AP remains byte-unchanged.

## Proposed addition
Add an optional hybrid branch when perspective setup itself is consuming design time or many camera variants must be tried. Use a simple 3D, photographic, or computer-generated underlay to lock **POV, lens/field impression, grid, and large volume proportions**; then return to drawing for section surfacing, design, and detail. Model only enough to solve the spatial scaffold.

The underlay is a perspective assistant, not permission to overmodel the final design. Robertson repeatedly warns that drawing can be faster than building every surface in 3D.

## Evidence
Scott Robertson with Thomas Bertling, *How to Draw*, printed pp. 58-61 (physical PDF pp. 56-59), plus application examples later in the book.

## Cumulative effect
Strengthens the shared-scene AP without making software a prerequisite. The hand-drawn path remains fully valid.
