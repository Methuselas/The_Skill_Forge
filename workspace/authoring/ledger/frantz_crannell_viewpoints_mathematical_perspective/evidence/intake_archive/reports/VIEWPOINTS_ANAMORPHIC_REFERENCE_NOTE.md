# Viewpoints Anamorphic / Forced-Perspective Reference Note

Chapter 7 and the movie interlude are retained as **reference**, not a new Perspective foundation.

Useful durable observations:
- An anamorphic image can be deliberately "wrong" from ordinary viewing positions and correct only from a designed station point.
- Grid transfer is a practical way to construct the required distortion when the subject is complex.
- Forced perspective is extremely sensitive to camera placement; small viewpoint shifts can destroy the illusion.
- A Hitchcock/dolly zoom changes viewpoint while changing image-plane/lens scale to hold one subject size, causing background spatial relationships to change.

These are valuable for special-effects composition, but the existing camera/viewfield and projection-choice logic already explains the underlying mechanism. No additional runtime card is created here.
