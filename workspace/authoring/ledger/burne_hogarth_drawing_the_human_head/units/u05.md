## Delta map

- VARIANT — **separate cranial proportion from facial projection**: salvage two independent large-form comparison axes from Hogarth's type chapter while discarding cephalic/population taxonomy and exact class thresholds.
- NEW DRILL — **map head variation across independent structural axes**: compare several real heads by cranial envelope and profile projection, then redraw selected heads with hair and local features removed so the large form must carry the difference.
- REJECTED — cephalic-index classes as anatomy doctrine, population/ethnic prediction, exact four-fifths/three-quarters thresholds, forehead-to-feature bundled rules, and exhaustive three-bin profile categories.
- REINFORCES — Loomis flexible head-type envelope, Bammes global proportion before feature detail, and Hogarth's own visual-conviction-over-exact-measurement warning.
