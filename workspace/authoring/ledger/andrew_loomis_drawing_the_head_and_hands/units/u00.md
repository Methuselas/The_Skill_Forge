## Delta map

- VARIANT — **vary head type by reshaping the governing cranial envelope before feature detail**. Loomis's dedicated source turns the standard cranial-ball construction into a generative type system: alter the large head/jaw/dome relationship first, then make feature spacing and local shapes inherit that changed whole.
- REVIEW — correct form/perspective/light before personality, stable skull versus mobile flesh, feature placement before detail, and whole-head three-dimensional construction all reinforce stronger committed rules already present.
- BOUNDARY — the same-volume squeezed-ball language is retained only as a design heuristic. For observed likeness, actual proportion wins; later sex/age categories are reviewed separately rather than treated as universal anatomy.
