## Delta map

- NEW DRILL — **construct a character head from a written description**. Loomis turns the construction system into an invention test: describe visible structural traits before drawing, build the large head type first, then make the local features answer that brief; repeat from another person's description to break habitual faces.
- VARIANT — **basic planes → secondary planes** as a deliberate bridge from the rounded cranial-ball construction to perspective and value modeling. The plane map is temporary and must yield to the observed anatomy rather than survive as generic faceting.
- VARIANT — **bone first, flesh second** as a character/likeness analysis order. Read whole shape, bony structure, and feature placement before movable cheek/mouth/eye flesh and before photographic surface detail.
- REINFORCES — whole-before-parts head construction, the divided Loomis cross/middle-line scaffold, average facial thirds as provisional measurement, skull-driven surface form, neck pivot mechanics, muzzle/eyeball roundness, shared scene perspective, and u00 head-type variation.
