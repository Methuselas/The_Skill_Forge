# Pattern Pressure-Test Rubric

Every tested Pattern receives all of these cases:

1. Positive — the Pattern clearly applies.
2. Negative — a superficially similar case belongs elsewhere or needs no action.
3. Boundary — the case sits near the Pattern's IF, ELSE, or exception boundary.
4. Adversarial — a simplistic literal reading is tempting and wrong.
5. Human evidence — professional work materially exercises the decision.
6. Competing owner — a neighboring Pattern is tested as a plausible but wrong
   owner where practical.

Every human fixture receives two passes:

- Diagnostic: what the current library correctly explains, permits, or rejects.
- Learning: what the successful work does that the library does not adequately
  explain, permit, route, or teach.

Intentional stylization is not a defect by default. Judge whether structure,
readability, hierarchy, rhythm, action, emotion, and the work's own visual
language remain coherent.
